# ArrDeck

A self-hosted media-stack command center — search, control, and monitor your
*arr stack (Sonarr / Radarr / SABnzbd / Prowlarr) from one clean interface,
at home or remote. Ships as an Android app and a Docker web UI.

> 🚧 Public repo scaffold. Full README, screenshots, install + Docker
> quick-start, and Releases are on the way.
